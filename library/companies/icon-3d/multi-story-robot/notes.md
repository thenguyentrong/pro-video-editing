# A Next-Gen Multi-Story Robot to Change the Way We Build  (ICON, 2025-09-11, 3:49, 16:9, YouTube, official ICON channel)
URL: https://www.youtube.com/watch?v=gNDWKbgQEWU
Purpose: product-development documentary / launch (why the company replaced its rail gantry printer with a tracked multi-story arm)
One-sentence point: Field feedback on the old gantry printer (rails, setup shifts, crew of 3-4, one storey) led ICON to a rail-less tracked arm that prints 27 ft tall with one operator, so other builders can use it.
